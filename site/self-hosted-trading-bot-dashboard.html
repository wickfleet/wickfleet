Self-hosted dashboards for Freqtrade bots compared

Freqtrade ships with FreqUI, and several open-source projects add a view over more than one bot. This page lists the ones we could verify from their own repositories on 2026-11-17: what each is, its license, its last release, and what it does and does not do by its own description. Wickfleet is one of them and this page is written by its author, so follow the links and check.

How this list was made

  • A project is listed when its repository carries an open-source license, had a commit in the last 12 months, and shows more than one Freqtrade bot
  • Every cell comes from the project's README, its release list or its code. Nothing here was measured or rated by us
  • No prices and no hosted services are listed
  • Projects change. The dates are from 2026-11-17

Wickfleet in short

Wickfleet keeps FreqUI for everything about one bot and adds a server next to it. The hub reads a git registry, starts and stops the bot containers to match, and puts every bot behind one address with one login.

The cost is one more service to run. The longer comparison with FreqUI is in the FAQ.

Try it

git clone https://github.com/wickfleet/wickfleet.git
cd wickfleet
make quickstart

Needs Docker with Compose v2, git and make, on macOS or Linux. Everything runs on one machine, bound to 127.0.0.1, and a dry-run demo bot is waiting in the fleet. More in the install guide, or look first at the read-only demo.

Wickfleet is software for running trading bots, not a recommendation to buy or sell anything. Backtests and replays describe the past, not the future. Every bot is a dry run on a simulated wallet by default.

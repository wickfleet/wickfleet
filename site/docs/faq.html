FAQ

How is Wickfleet different from FreqUI's own multi-bot view?

Wickfleet is built on FreqUI, not instead of it. FreqUI is the cockpit for one bot, and it already handles several: you add each bot's URL and login in the browser, switch between them, and its bot comparison view shows them side by side. With one or two bots that is often all you need.

FreqUI deliberately has no backend of its own. Its maintainer has explained why in the issue tracker (#1094, #2565): there is no main server to keep shared settings, making one bot the master is wrong because that bot may be replaced tomorrow, pushing credentials to every bot is not acceptable, and a user-supplied backend would be unmaintainable. He also keeps balance out of the summary row on purpose, because a total that mixes dry and live money, or USDT and BTC, means nothing. Those are sound reasons for a UI that talks to bots directly.

Wickfleet adds the server FreqUI chose not to have, and keeps FreqUI for everything about a single bot. For someone running three or more bots that means:

  • The bot list lives on the server, so every browser and device sees the same fleet without adding bots again
  • Bot API keys stay on the server. You log in once, the hub adds each bot's key per request
  • A git-backed registry: every bot and strategy is a file, every change is a commit, and the hub starts and stops the containers to match
  • A replay gate: lookahead and recursive analysis plus a walk-forward and Monte Carlo verdict, which live trading requires
  • Fleet views that total per stake currency and keep dry and live apart, plus Compare and Risk across bots
  • Roles (viewer, operator, admin) when you want to show the fleet to someone without letting them trade

The cost is one more service to run. If you do not need any of that, plain FreqUI is simpler.

Should I put Wickfleet on the internet?

Keep it private by default: run it on your own machine, or on a server you reach over a VPN such as Tailscale, NetBird or WireGuard. If it has to be public, put it behind your own reverse proxy with TLS and single sign-on and run the hub in proxy mode with oauth2-proxy in front. Bot API keys and exchange keys stay on the host that runs the bots and never reach the browser.

Where do I get help?

Bugs and feature requests: GitHub issues, with a template for each. Questions about Freqtrade itself, strategies and exchanges belong in the Freqtrade Discord. Issues are triaged in the evenings, so expect a day or two.

Is Wickfleet a fork of FreqUI?

The UI is: wickfleet-ui is a fork of FreqUI with the Wickfleet pages added, kept close to upstream. The hub is new code in Go. Both are GPL-3.0.

Does it trade real money?

Not by default. Every bot is a dry run on a simulated wallet. Live trading needs an explicit switch on the instance and on the bot, a passing replay of exactly those settings from the last 7 days, and exchange keys from files on the host. Nothing on this site is financial advice.

Which exchanges work?

Any exchange Freqtrade supports, set per bot. The examples use Binance because it has deep candle history for replays.

Can I keep my existing Freqtrade bots?

Wickfleet runs the bots it manages in its own containers from the registry. A bot becomes a registry file: exchange, pairs, stake and strategy. A hand-written strategy .py in the registry runs as is.

What does it cost?

Nothing. It is free software under the GPL-3.0, you run it on your own machine.

Does the strategy builder use AI?

Optionally. A spec can be built from blocks without any model. Drafting a spec from a sentence needs an Ollama or Anthropic endpoint you configure, and the model only proposes JSON that the hub validates against a whitelist.

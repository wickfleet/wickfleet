Wickfleet docs

FreqUI is the cockpit for one bot. Wickfleet runs the fleet: a small server and a FreqUI fork for people who run three or more Freqtrade bots. These pages cover running it and the fleet views. The full reference, every endpoint and setting, is the README on GitHub.

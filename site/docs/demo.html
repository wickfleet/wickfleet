Demo mode

With WICKFLEET_AUTH=demo the hub runs a public read-only instance. Try one at demo.wickfleet.com.

What changes

In demo mode
Who you areevery visitor is the viewer demo and sees the bots with owner: demo
Writesthe hub answers only GET, HEAD and OPTIONS. Everything else is 403
Botscalls to a bot pass only as reads, plus the FreqUI token login
Moneyviewer rules: no balances, absolute profit or exposure lists
Compareshows comparisons already on disk, refuses new ones
Identity headersclient X-Auth-Request-* headers are dropped
Live tradingthe hub refuses to start when WICKFLEET_LIVE_TRADING is on

Run your own

  1. Start from examples/registry, with the two bots in examples/demo/bots/ in place of bots/demo.yaml. Both are dry runs owned by demo
  2. Set WICKFLEET_AUTH=demo on the hub
  3. Keep the registry read-only: leave WICKFLEET_REGISTRY_WRITE_URL unset
  4. To show a comparison, run it on an instance with a login over the same registry and state dir, then switch to demo mode

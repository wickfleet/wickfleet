# Wickfleet hub v0.2.0

Second public release of the hub. Pair it with Wickfleet UI v0.2.0, which has
the pages for the new endpoints.

## New

| What | Detail |
|---|---|
| Compare | `POST /hub/api/compare` replays 2 to 12 bots over one window, as ordinary replay jobs queued one at a time. Each bot gets freqtrade's own figures (profit, drawdown, Sharpe, Sortino, Calmar, profit factor, win rate, trades), the walk-forward and Monte Carlo verdict and a daily equity curve on shared dates. The newest 50 comparisons are kept in `<WICKFLEET_STATE_DIR>/comparisons/` |
| Risk | `GET /hub/api/risk` reads each visible bot's `/status`, `/profit` and `/balance`, cached 30 s: open trades, capital at stake, exposure per pair and per base coin, drawdown against the worst so far, stoploss distance and pairs that two or more bots trade. Dry and live are never summed together. A bot that does not answer is listed with its error and left out of the sums |
| Viewers see no money | viewers, and every visitor of a demo instance, get percentages, ratios, counts and verdicts only. Balances, absolute profit, equity in currency and exposure lists are removed on the server, not hidden in the browser |
| Demo and compare | a read-only demo (`WICKFLEET_AUTH=demo`) shows the comparisons already kept on disk and refuses new ones (403) |
| Website | wickfleet.com has docs pages (install, roles and login, Compare, Risk, demo mode, FAQ), search titles, Open Graph cards, a sitemap and a real 404. `make site-check` gates tags and links in CI |
| README | a short recording of the Compare and Risk pages at the top, seen as a viewer so no amounts show |
| Support | bug and feature issue templates on GitHub. Freqtrade questions go to the Freqtrade Discord. The docs say how to keep an instance private (VPN) or expose it safely (reverse proxy with SSO, `proxy` mode) |

## Fixes and maintenance

| What | Detail |
|---|---|
| Go 1.27.4 | GO-2026-6859 (net/http `MaxBytesReader` header race) was reachable through the hub and the docker guard. go.mod and the image build move to `golang:1.27.4-trixie`, pinned by digest |

## Upgrade from v0.1.0

| Item | Change |
|---|---|
| Images | `ghcr.io/wickfleet/wickfleet-hub:0.2.0` and `ghcr.io/wickfleet/wickfleet-ui:0.2.1` (the UI 0.2.0 image did not build on arm64, 0.2.1 is the same code with the build fix), amd64 and arm64. `latest` moves to them. Upgrade both together |
| Compose quick start | `git pull`, `docker pull ghcr.io/wickfleet/wickfleet-ui:latest`, then `make quickstart` again. The quick start builds the hub from your checkout and keeps `deploy/compose/data`. Pin versions with `WICKFLEET_HUB_IMAGE` and `WICKFLEET_UI_IMAGE` |
| Environment | no new variables. Comparisons live under the existing `WICKFLEET_STATE_DIR`, which must be writable by the hub (it already is in the quick start) |
| Registry | no format change |
| Live trading | unchanged: still off unless the instance sets `WICKFLEET_LIVE_TRADING=true` |

## Credit

Wickfleet runs [Freqtrade](https://www.freqtrade.io) bots and its UI is a fork of
[FreqUI](https://github.com/freqtrade/frequi), both by Matthias Voppichler and
contributors. Every figure on the Compare page is freqtrade's own backtest
output. Thank you.

## Not financial advice

Replays and comparisons describe the past, not the future. Bots run as dry runs
by default. See the README disclaimer.
